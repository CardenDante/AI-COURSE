# Week 4 AI Assignment — Submission Instructions

You will create a public GitHub repository, complete the assignment inside it, and then submit the repository link in Google Classroom.

---

## Step 1 — Create a GitHub Repository

1. Log in to **GitHub**
2. Click **New Repository**
3. Name the repository: `week4-ai-assignment`
4. Set the repository to **Public**
5. Initialize it with a **README.md**
6. Click **Create Repository**

---

## Step 2 — Repository Structure

Your repository must contain the following files:

```
week4-ai-assignment/
│
├── README.md
└── assignment.py
```

---

## Step 3 — Theory Questions (`README.md`)

All non-programming questions must be answered inside `README.md`.

Write your answers in **Markdown format** and organize them clearly.

Your README should include:

- Your **Name**
- The **assignment title**
- Answers to the **theory questions**

### Example Structure

```markdown
# Week 4 Assignment

Name: Your Name

## Question 1
Your answer here

## Question 2
Your answer here

## Question 3
Your answer here
```

> Your answers should be clear, well written, and properly formatted.

---

## Step 4 — Python Programming Questions

Create a file called: `assignment.py`

All Python programming questions should be written inside this file.

Include **comments** to indicate which question you are answering.

### Example Format

```python
# Question 4
# Your code here

# Question 5
# Your code here
```

> Make sure your code runs without errors.

---

## Step 5 — Upload to GitHub

Upload both files to your repository:

- `README.md`
- `assignment.py`

Verify that they appear in your repository.

---

## Step 6 — Submit Your Repository

1. Open **Google Classroom**
2. Go to **Week 4 Assignment**
3. Paste your **GitHub repository link**
4. Click **Turn In**

### Example Format

```
https://github.com/yourusername/week4-ai-assignment
```

---

## Important Rules

- The repository **must be public**
- All work **must be your own**
- The README **must be written using Markdown**
- Code **must be clear and organized**
